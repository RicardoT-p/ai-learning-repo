# AI 数据工程师作品集

项目按顺序学习，不要同时开工：

1. `01_async_crawler`：`asyncio`、并发限制、重试、robots.txt、JSONL。
2. `02_scrapy_crawler`：Scrapy 调度、去重、限速、断点续爬。
3. `03_training_data_pipeline`：清洗、脱敏、精确去重、近似去重、统计。
4. `04_llm_feedback_eval`：SQLite 反馈库、固定评测集、回归报告。
5. `05_datatrove_pipeline`：DataTrove 训练语料流水线。
6. `06_polars_duckdb_quality`：Polars + DuckDB 数据质量分析。
7. `07_airflow_workflow`：Airflow 工作流编排。
8. `08_argilla_feedback`：人工反馈与偏好标注。
9. `09_rag_eval_observability`：Ragas + Phoenix 评测与追踪。
10. `10_ray_distributed_pipeline`：Ray Data 分布式处理。

## 建议节奏

每个项目都按下面四步学习：

1. 先照 README 跑通。
2. 从程序入口开始逐行阅读。
3. 完成 README 中的练习。
4. 不看答案，重新写一个更小的版本。

所有采集示例只用于你有权访问的网页，并遵守网站服务条款、robots.txt 和限速要求。
